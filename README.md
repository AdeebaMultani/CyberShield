# 🛡️ CyberSheild
### See the Threat. Understand the Risk. Stay Ahead.

**Your cybersecurity intelligence hub — bringing vulnerability monitoring and threat intelligence together in one place.**

Cyber threats are evolving every day. Keeping track of vulnerabilities shouldn't be complicated.

**CyberSheild** is a Python & Django-based cybersecurity platform being developed to collect, organize, and analyze vulnerability intelligence from trusted public security sources — making complex security information easier to explore and understand.

---

## ⚡ What's Inside?

🔍 **Vulnerability Explorer**  
Explore CVEs, understand their descriptions, and discover affected products.

🚨 **Threat Monitoring**  
Keep track of security threats and important vulnerability updates.

📊 **Security Dashboard**  
Get a clear overview of vulnerability severity, trends, and security insights.

🎯 **Severity Analysis**  
Understand vulnerability risk through CVSS scores and severity classifications.

🤖 **AI Security Assistant**  
Get simplified explanations and summaries of complex cybersecurity information.

🔔 **Smart Alerts**  
Stay informed about newly discovered and high-priority vulnerabilities.

## 🚀 Getting Started

Want to explore CyberSheild locally?

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/CyberSheild.git
```

**2. Navigate to the project**

```bash
cd CyberSheild
```

**3. Create a virtual environment**

```bash
python -m venv .venv
```

**4. Activate it (Windows)**

```powershell
.venv\Scripts\Activate.ps1
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Apply migrations**

```bash
python manage.py migrate
```

**7. Start the development server**

```bash
python manage.py runserver
```

Open: http://127.0.0.1:8000/
